# VigenereCipher
Coding an encryption and decryption system using the Vigenère Cipher

Similar to Caesar Cipher but instead we use a keyword, break it down into its index within the alphabet then shift each plaintext letter by its corresponding keyword letter’s index then repeat with every letter after. For example, if we use “Hello World” as the plaintext and “key” as the keyword, we convert the key into a spaceless, lowercase key then all the letters in the plaintext are turned into lowercase then we iterate through the plaintext to convert into a list which is then mapped using the keyword. Modular arithmetic is used for if the keyword is shorter than the plaintext so that it wraps around to the start of the keyword and continues mapping. “key” is shorter than “Hello World” so, after the first “l” is mapped, we return to the start and map the second “l” with “k”. The encryption simply iterates between the list form of “Hello World” and the mapped keyword then shifts each letter in “Hello World” by the corresponding letter’s index in the keyword.
